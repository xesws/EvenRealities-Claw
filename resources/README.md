## 为什么只有两张

原来这里有六张（全景 / 分页两张 / 配对屏 / W6 徽记对照两张），**全部删掉了** ——
它们是浏览器夹具那个字形排布 bug 修好**之前**截的：夹具把每个字形塞进 G2 的
advance 盒子时没有按浏览器字体的实际宽度缩放，于是拉丁字母互相重叠、笔画被吃掉。
截图上能直接读到 `kern:ng`（kerning）、`textCo¯or`（textColor）、`f:xture`（fixture）
这样的字。修法见 `plugin/harness/mock.ts` 的 `browserWidth()`：逐字形用 canvas
`measureText` 量出浏览器宽度，再 `scaleX` 缩到固件的 advance 上。

**一张读不准的截图比没有截图更糟**，所以宁可少。以下覆盖面暂时空着，等要用的时候
再补（服务起着就能截）：配对屏、W6 徽记对照（真 agent vs 测试替身）、跨页锚点与页脚
`1/2 ›`、整机全景。
